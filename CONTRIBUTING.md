# Contributing

1. Keep account-month snapshots unique and preserve a consistent revenue currency.
2. Document cohort, churn, expansion, and NRR definitions when they change.
3. Do not commit customer data; use synthetic snapshots for examples.
4. Treat propensity scores as exploratory unless temporal validation and calibration are added.
5. Use a focused branch and summarize metric changes in the pull request.

The CI workflow currently checks dependency installation and Python compilation.
